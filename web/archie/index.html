Time Pilot · Acorn Archimedes

RISC OS 3.11 on an A3020
A3020 · 4 MB · auto-boots !TimePilot Open full tab ↗

It starts itself. Archimedes Live unpacks the HostFS archive and boots !TimePilot. Click the emulator once to give it focus, then press 1 or 2 on the title screen to start. If the toolbar is cut off in a narrow window, use Open full tab.

Machine profile

This page embeds Archimedes Live with a share URL that loads the emulator-ready HostFS archive over CORS, unpacks it into HostFS, and runs filer_run HostFS:$.!TimePilot from the autoboot !Boot file. No local emulator or manual file drop is needed.

Machine
Acorn A3020, ARM250 @ 12 MHz, 4 MB RAM
System
RISC OS 3.11
Game archive
TimePilot-RISCOS-HostFS.zip from the TimePilot-Archie V1.9 release
Emulator
Archimedes Live (external, WebAssembly / Arculator)

The HostFS archive is used because Archimedes Live unpacks that variant with RISC OS file types intact (!Run,feb, !RunImage,ff8). The plain hardware archive TimePilot-RISCOS.zip has no comma file-type metadata, so it cannot be turned into a running application by the emulator.
