# Apple II + VERA Release v1.91

Version 1.91 adds file-level installation support for the Apple II + VERA HDV build.

## What's new

- **Install to another ProDOS volume or directory:** Copy all files from `TimePilot-IIvera.hdv` into your target ProDOS volume or directory, except `PRODOS`. The files no longer need to keep the same block allocation as in the original HDV.
- **Game directory detection:** The HDV now includes a `TIME.PILOT` marker file. Keep it with the game files; `TPILOT.SYSTEM` checks for it before loading the game, and the game checks it before opening `ART` and `PCM`.
- **Volume identification:** The HDV volume name is set to `TIME.PILOT` during image creation.
- **ProDOS timestamps:** Newly generated game file entries receive the local build date and time, encoded with ProDOS Y2K year handling. The volume header's ProDOS metadata is preserved.
- **File-based loading:** The loader reads `MAIN.BIN` or `MAIN4.BIN`, and the game reads `ART` and `PCM`, by filename from the active ProDOS prefix.
- **Dual-floppy edition:** The two 140 KB images keep their fixed-block layout, with volume names `TIME.PILOT` and `TIME.PILOT.2`. They are intended only for a dual-floppy setup. Do not copy them into separate hard-disk directories; use the HDV edition for hard-disk installation.
- **Separate loader paths:** HDV launches use ProDOS file reads; dual-floppy launches use their own `READ_BLOCK` trampoline to load `MAIN.BIN`/`MAIN4.BIN` from the correct disk.
- **Legacy HDV compatibility:** Older HDV images retain the fixed-block fallback.
- Generated file entries on both floppy disks receive local build timestamps.
- Updated the loader splash to display version `v1.91`.

## Installation

For hard-disk installation, use the HDV image. Copy all files from the HDV image into the same target ProDOS volume or directory, except `PRODOS`. Keep `TIME.PILOT` alongside the game files, set the ProDOS prefix to that location, and launch `TPILOT.SYSTEM`. The dual-floppy images are only for use as a two-disk floppy set.

The packaged HDV volume name is `TIME.PILOT`.

The file-level install was verified by copying the game into another ProDOS location and launching it there.
