What this is, the controls, and the notices

What you are running

The actual TimePilot-CX16 PRG, cross-compiled with llvm-mos and loaded into the emulator's HostFS virtual drive with -prg time_pilot.prg -run. The 43 audio banks, sprite VRAM and font VRAM are copied alongside it. The emulator is the official X16Community WebAssembly release r49, fetched and checksum-checked at build time; it is not vendored in this repository.

Controls (keyboard)

KeysAction
Arrow keysMove left / right / up / down
[ / ]Rotate left / right
1 / SpaceFire
2Two-player game
P / EscPause / quit

The emulator keeps the X16 en-us keyboard layout, so physical key positions are what the KERNAL sees. The browser build runs with the joystick scan disabled; the keyboard path is fully wired.

Notes

The official r49 WebAssembly build used here does not enable VERA PCM audio, so this player is silent. The native WebAssembly port on the front page has audio. “Fullscreen” scales the 640×480 VERA screen. The first boot takes a few seconds while the 46 game files are copied into the emulator's memory.
