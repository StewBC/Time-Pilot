Under the hood

What is running

Native WebAssembly port

TimePilot-16bit-C is compiled by Emscripten against a small headless tigr platform layer. The game's synchronous main loop is paced with Asyncify at logical frame boundaries, and the OpenAL/ALUT calls are mapped to WebAudio. The whole game and its sprites, fonts and audio banks are preloaded into MEMFS, so the page runs from static files — no server-side game logic.

Commander X16

TimePilot-CX16 is cross-compiled with llvm-mos to a PRG with a SYS start address, then loaded into the official X16Community WebAssembly emulator (r49). The player fetches the PRG, sprite VRAM, font VRAM and 43 audio banks into the emulator's HostFS drive and starts it with -prg time_pilot.prg -run. The emulator binary is downloaded and checksum-verified at build time; it is not vendored here.

Apple II, Macintosh and Archimedes links

The Apple II + VERA build is hosted as a GitHub release asset and loaded straight into a2vera. The IIgs card opens a2gsemu's Apple IIgs core with the TimePilot game URL passed to the emulator. Both are external links, not iframes, so the emulators' own keyboard and audio handling stays intact.

The Macintosh card opens a page with Infinite Mac embedded. Infinite Mac boots System 7.5 and fetches mac/Time.Pilot-m68k.dsk as a second disk; the disk and the emulator are both external to the WASM/X16 players.

The Archimedes card embeds Archimedes Live. Its hash carries the disc URL for archie/TimePilot-RISCOS-HostFS.zip and an autoboot command, so the archive is unpacked onto HostFS and the game starts without a local file picker.

Build and deploy

GitHub Actions rebuilds both local players from source on every push to master, assembles this static site, and deploys it to GitHub Pages. The Emscripten SDK, llvm-mos SDK and x16-emulator archive are fetched by the build scripts into caches outside the repository, so the checkout stays small and reproducible.
