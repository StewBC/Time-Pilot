Controls

Rotate with [ ], move with the arrow keys, fire with 1 or Space, pause with P. Press J on the title screen to scan for a joystick. Esc asks before leaving the game. A connected gamepad also works; on a touchscreen use the buttons below.

About this port

This is Stefan Wessels' 16-bit C version, compiled to WebAssembly and rendered at its native 320×200 resolution. The graphics backend is a custom browser implementation of the tigr API; sound uses the Web Audio API. No desktop emulator is involved.
