Time Pilot · Macintosh 68K

System 7.5 on a Quadra 650
Quadra 650 · 8 MB · Time.Pilot mounted Open full tab ↗

The Mac is already booting. Wait for the System 7.5 desktop, open Time.Pilot if needed, then double-click TimePilot. Click the screen once to give the emulator focus. If the picture is cut off in a narrow window, use Open full tab.

Machine profile

Infinite Mac boots System 7.5 and mounts the hosted Time.Pilot-m68k.dsk as a second drive. No download and no local emulator install is required; the first boot takes a few seconds while the runtime and disk chunks download.

Machine
Macintosh Quadra 650 (Basilisk II), 68040
System
System 7.5, 640×480, 8 MB RAM
Game disk
Time.Pilot-m68k.dsk from the TimePilot-Mac68k V1.9 release
Emulator
Infinite Mac (external, WebAssembly)

The emulator is Infinite Mac; this page only supplies the 800 KB game floppy and the URL parameters. The disk is fetched from raw.githubusercontent.com for the same repository, because Infinite Mac needs a HEAD with `Content-Length` plus byte-range GETs. The build stamps the repository slug, so a fork fetches its own copy.
